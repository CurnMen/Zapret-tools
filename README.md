# 🔀 Zapret Tools

Удобный нативный графический интерфейс (GUI) для управления сборкой обхода блокировок **Zapret** (от Flowseal) на Windows.

Приложение написано на **Tauri 2 + Rust** и потребляет минимум оперативной памяти, при этом предоставляя мощные инструменты для работы со списками доменов и управления службами.

## ✨ Основные возможности

* **🚀 Управление службой в один клик:** Установка, запуск, остановка и удаление службы Windows `zapret` без необходимости открывать черные консольные окна.
* **📂 Умное автоопределение:** Программа сама находит запущенный процесс `winws.exe` (даже если он скрыт под службой) и автоматически переключается на его папку.
* **📝 Продвинутый редактор списков:**
  * Боковая панель с номерами строк (как в VS Code).
  * Умный поиск по файлу (с кнопкой «Далее»).
  * Поддержка Drag & Drop (перетаскивание `.txt` файлов для слияния).
  * Подсветка синтаксических ошибок в реальном времени.
* **🌐 Поддержка кириллицы (.рф):** Автоматическая конвертация доменов вида `яндекс.рф` в формат Punycode (`xn--...`), который понимает Zapret.
* **✨ Безопасная очистка:** Удаление дубликатов, пустых строк и мусора с сохранением структуры.
* **🗑️ Корзина:** Если вы случайно удалили важный домен и нажали «Сохранить», не беда! Все удаленные строки попадают в корзину, откуда их можно восстановить.
* **📥 Автообновление:** Скачивание новых версий Zapret прямо с GitHub с автоматическим переносом ваших списков и настроек фильтров.
* **🖥️ Интеграция с Windows:** Работа в системном трее (возле часов) и поддержка автозапуска при старте системы.

## 🚀 Как начать пользоваться?

1. Перейди в раздел [Releases](../../releases) на этом GitHub.
2. Скачай файл `zapret-tools.exe` (портативный десктопный exe) или `Zapret.Tools_<версия>_x64-setup.exe` (инсталлятор) — см. тег релиза.
3. Помести его в любую удобную папку (например, прямо в корень `E:\zapret`).
4. Запусти программу, нажми «Выбрать папку Zapret» и укажи путь к папке, где лежат версии Zapret.
5. Готово! Программа сама найдет активную версию и предложит управление.

*Примечание: Для работы программы на Windows 10/11 нужен встроенный компонент WebView2 (в Windows 11 он есть по умолчанию).*

## 📥 Что внутри релиза

Каждый релиз — это сборка указанного тега. В релизе обычно лежит:

* `zapret-tools.exe` — портативный exe (файл, который ещё и запускает свитчер).
* `Zapret.Tools_<версия>_x64-setup.exe` — NSIS-инсталлятор (та же сборка, ставится в выбранную папку и создаёт ярлык). Локальная сборка даёт файл с пробелом — `Zapret Tools_<версия>_x64-setup.exe`; на GitHub такой пробел заменяется точкой. Настройки при этом хранятся в `%APPDATA%\com.zapret.tools\config.json` и переустановку переживают.

Тег [Zapret-Tools-V1.3](https://github.com/CurnMen/Zapret-tools/releases/tag/Zapret-Tools-V1.3) указывает на ревизию `a0d9a3b`, а версия `1.3.1` в `package.json` появилась отдельным коммитом `c5cdc7c` уже после тега. `cargo test --lib` проходит 49 тестов.

*Перед тем как загрузить новый релиз, убедись, что тег совпадает с версией в `package.json`. Если в `package.json` версия не та — собери заново.*

## 🔄 Обновление самого приложения

Проверка обновлений идёт через `tauri-plugin-updater`: приложение берёт `latest.json` из релиза
`https://github.com/CurnMen/Zapret-tools/releases/latest/download/latest.json` и проверяет подпись
публичным ключом из `src-tauri/tauri.conf.json` (`plugins.updater.pubkey`).

**Приватный ключ:** `src-tauri/keys/zapret-tools.key` — он в `.gitignore` и в репозиторий не попадает.
Потеряешь его — обновления больше не подписать, придётся менять `pubkey` в новой версии вручную.

**Как выпустить обновление:**

1. Подними версию в `package.json` (`npm version patch --no-git-tag-version`).
2. Поставь тег и запушь его: `git tag Zapret-Tools-V1.4 && git push origin Zapret-Tools-V1.4`.
3. Workflow `.github/workflows/release.yml` соберёт NSIS, подпишет артефакты и опубликует релиз вместе с `latest.json`.

Один раз перед первым релизом добавь в GitHub → Settings → Secrets and variables → Actions:

* `TAURI_SIGNING_PRIVATE_KEY` — содержимое файла `src-tauri/keys/zapret-tools.key`;
* `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` — пароль ключа (сейчас ключ без пароля, можно оставить пустым).

Локальная сборка с подписью (PowerShell):
```powershell
$env:TAURI_SIGNING_PRIVATE_KEY = 'src-tauri\keys\zapret-tools.key'
npm run tauri build
```
Рядом с инсталлятором появится файл `.sig`. `npm run redeploy` подставляет ключ сам.

## 🛠️ Для разработчиков (Сборка из исходников)


Если вы хотите внести изменения в код и собрать `.exe` самостоятельно.

**Требования:**
* [Rust](https://rustup.rs/) (с компонентом MSVC)
* [Node.js](https://nodejs.org/) (LTS версия)
* [Visual Studio C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)

**Сборка:**
```bash
# 1. Клонируйте репозиторий
git clone https://github.com/CurnMen/Zapret-tools.git
cd Zapret-tools

# 2. Установите зависимости фронтенда
npm install

# 3. Запустите в режиме разработки
npm run tauri dev

# 4. Соберите релизную версию (появится в src-tauri/target/release/)
npm run tauri build
```

## 🔁 Пересборка установленной копии

Если приложение установлено через NSIS, ставить инсталлятор руками после каждой правки
не нужно:

```powershell
npm run redeploy
```

Скрипт `scripts/redeploy.ps1` соберёт релиз, подставит локальный ключ подписи
(`src-tauri/keys/zapret-tools.key`), остановит запущенную установленную копию, тихо
поставит новую поверх неё в тот же каталог и запустит. Каталог берётся из записи
деинсталлятора, поэтому нестандартный путь установки (например, `E:\zapret\Zapret Tools`)
находится сам. Настройки в `%APPDATA%\com.zapret.tools` не затрагиваются.

Только переустановить последнюю сборку без компиляции: `npm run redeploy -- -SkipBuild`.

## ⌨️ Консольный интерфейс (для агентов и скриптов)

Тот же `zapret-tools.exe` работает и без окна: команда `cli` выполняет операцию и печатает
результат в JSON. GUI при этом не запускается.

```powershell
$exe = 'E:\zapret\Zapret Tools\zapret-tools.exe'

& $exe cli status                 # версия, конфиг, версии Zapret, запущенный winws
& $exe cli versions               # папки версий в корне
& $exe cli lists                  # файлы списков и число строк
& $exe cli get domains.txt --raw  # содержимое списка как текст
Get-Content domains.txt | & $exe cli set domains.txt --from -   # сохранить список
& $exe cli help                   # все команды
```

Списки сохраняются по тем же правилам, что и в окне: дубликаты и пустые строки
удаляются, удалённые строки уходят в корзину `zapret_trash`.

Ошибка возвращается как `{"error": "..."}` в stderr с кодом 1, неверный вызов — с кодом 2.
Корень Zapret и активная версия по умолчанию берутся из
`%APPDATA%\com.zapret.tools\config.json` и переопределяются `--root PATH` и
`--version PATH`. Команды `service`, `dns` и `quic` меняют систему и запрашивают права
администратора (UAC). Свитчер раскладки управляется только из окна программы.
