# Изменения

Версия приложения берётся из `package.json`: `tauri.conf.json` ссылается на него
(`"version": "../package.json"`), а `Cargo.toml` держит только версию крейта.
При релизе правится одно место — `package.json`.

## 1.0.0 — 21.11.2026

### Свитчер раскладки

- Исправление слова переведено на встроенные словари: сеть для обычной работы не нужна.
- Буфер обмена вынесен в модуль `clipboard.rs`; чтение различает три состояния:
  текст, доказанно пустой буфер и «прочитать не удалось».
- Восстановление буфера не стирает картинки, файлы и транзитные состояния Windows:
  очистка выполняется только при доказанной пустоте (`EnumClipboardFormats`).
- Исправлен выход за границы при чтении буфера с `GlobalSize = 0`.
- Поколения буфера не дают старому восстановлению затереть текст более новой правки.
- Запись в лог сериализована, строки больше не склеиваются.
- После сбоя перехвата свитчер можно запустить заново без перезапуска приложения.
- Паника в фоновом потоке попадает в лог и в окно, а не теряется молча.
- Double Shift и восстановление буфера покрыты таблицами тестов.

### Сеть

- Список интерфейсов, DNS и состояние правила QUIC читаются через IP Helper и COM:
  ~0,04 с вместо ~8,6 с. Пути через PowerShell оставлены резервными.
- Вкладка «Сеть» показывает загрузку и не даёт повторно нажимать кнопки.

### Свитчер: пользовательский словарь

- Свой словарь RU/EN: слова добавляются вручную и участвуют в автоправке наравне со встроенными.
- Если перевод слова не найден во встроенных словарях, приходит предложение «Добавить в словарь?».
- Отклонённые предложения запоминаются и больше не показываются; отказ можно снять
  в любой момент: он хранит пару слов, поэтому возвращается в список предложений,
  а не просто исчезает из памяти.
- «Добавить в словарь?» сохраняет только переведённое слово: исходный набор в словарь
  не попадает.
- Предложения не теряются: каждое падает в список «Предложения словаря» (лимит 30,
  дубликаты склеиваются), на вкладке «Свитчер» появляется счётчик. Из списка можно
  «Добавить», «Скрыть» или «Добавить все».
- Пользовательский словарь — один общий список (RU и EN вместе, у слова метка языка),
  ограниченный по высоте: длинный словарь не расталкивает вкладку.
- Отклонённые предложения — отдельный компактный блок из чипов; он виден, даже когда
  очередь предложений пуста. Кнопка «↺» снимает отказ и возвращает пару в предложения.
- Строки всех списков одной высоты (32 px), длинный текст обрезается многоточием.

### hosts и тесты Zapret

- «Авто-обновить из Zapret»: скачивает hosts Flowseal, заменяет блок между маркерами
  `# >>> Zapret Tools Auto-Hosts >>>` / `# <<< Zapret Tools Auto-Hosts <<<`, пишет через UAC
  и сбрасывает DNS-кеш.
- «Запустить тесты Zapret» на вкладке «Версии»: `utils\test zapret.ps1` выполняется скрыто,
  вывод построчно попадает в консоль.
- Перед тестами спрашивается подтверждение: прогон идёт до 30 минут и перезапускает `winws`.
- Вывод PowerShell читается в OEM-кодировке (cp866): кириллица в консоли больше не `����`.

### Диагностика

- Лог получил локальное время (`2026-11-21 18:05:34.889`) и ротацию при 2 МБ.
- Новая вкладка «Диагностика»: последние 200 строк лога, открытие файла и копирование.

### Безопасность и сборка

- UAC-скрипты больше не пишутся в `%TEMP%`: код передаётся через `-EncodedCommand`,
  подменить файл до подтверждения прав нельзя (TOCTOU).
- Скрипт вынесен из `index.html` в `src/app.js`; CSP разрешает только внешние скрипты
  (`script-src 'self'` без `'unsafe-inline'`), внешние источники и `object-src` закрыты.
  Инлайн-стили и `style`-атрибуты остаются разрешены (`style-src-attr`): Tauri добавляет
  nonce в `style-src`, из-за чего `'unsafe-inline'` там игнорируется.
- Вывод логов и имён файлов идёт через `textContent`/DOM-узлы: разметка из данных
  (имена версий, корзина, ошибки) больше не исполняется как HTML.
- Пути IPC-команд проверяются на простое имя, вложенность в корень версий и допустимый
  тег; файл hosts для UAC создаётся со случайным именем и удерживается открытым
  с `FILE_SHARE_READ` до конца записи.
- CI на GitHub Actions (Windows): `cargo fmt --check`, `cargo clippy -D warnings`,
  `cargo test --lib`, `cargo build --release`.
- `cargo test --lib`: 49 тестов (парсеры, флаги службы, буфер, Double Shift, Base64 для UAC,
  декодирование OEM-вывода, старый и новый формат отклонённых предложений, проверки путей
  и удержание временного файла hosts).
