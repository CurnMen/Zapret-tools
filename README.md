# 🔀 Zapret Tools

Удобный нативный графический интерфейс (GUI) для управления сборкой обхода блокировок **Zapret** (от Flowseal) на Windows.

Приложение написано на **Tauri 2 + Rust** и потребляет минимум оперативной памяти, при этом предоставляя мощные инструменты для работы со списками доменов и управления службами.

## ✨ Основные возможности

* **🚀 Управление службой в один клик:** Установка, запуск, остановка и удаление службы Windows `zapret` без необходимости открывать черные консольные окна.
* **📂 Умное автоопределение:** Программа сама находит запущенный процесс `winws.exe` (даже если он скрыт под службой) и автоматически переключается на его папку.
* **📝 Продвинутый редактор списков:**
  * Боковая панель с номерами строк (как в VS Code).
  * Умный поиск по файлу (с кнопкой «Далее»).
  * Поддержка Drag & Drop (перетаскивание `.txt` файлов для слияния).
  * Подсветка синтаксических ошибок в реальном времени.
* **🌐 Поддержка кириллицы (.рф):** Автоматическая конвертация доменов вида `яндекс.рф` в формат Punycode (`xn--...`), который понимает Zapret.
* **✨ Безопасная очистка:** Удаление дубликатов, пустых строк и мусора с сохранением структуры.
* **🗑️ Корзина:** Если вы случайно удалили важный домен и нажали «Сохранить», не беда! Все удаленные строки попадают в корзину, откуда их можно восстановить.
* **📥 Автообновление:** Скачивание новых версий Zapret прямо с GitHub с автоматическим переносом ваших списков и настроек фильтров.
* **🖥️ Интеграция с Windows:** Работа в системном трее (возле часов) и поддержка автозапуска при старте системы.

## 🚀 Как начать пользоваться?

1. Перейди в раздел [Releases](../../releases) на этом GitHub.
2. Скачай последний файл **`ZapretTools.exe`**.
3. Помести его в любую удобную папку (например, прямо в корень `E:\zapret`).
4. Запусти программу, нажми **«Выбрать папку Zapret»** и укажи путь к папке, где лежат версии Zapret.
5. Готово! Программа сама найдет активную версию и предложит управление.

*Примечание: Для работы программы на Windows 10/11 нужен встроенный компонент WebView2 (в Windows 11 он есть по умолчанию).*

## 🛠️ Для разработчиков (Сборка из исходников)

Если вы хотите внести изменения в код и собрать `.exe` самостоятельно.

**Требования:**
* [Rust](https://rustup.rs/) (с компонентом MSVC)
* [Node.js](https://nodejs.org/) (LTS версия)
* [Visual Studio C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)

**Сборка:**
```bash
# 1. Клонируйте репозиторий
git clone https://github.com/CurnMen/Zapret-tools.git
cd Zapret-tools

# 2. Установите зависимости фронтенда
npm install

# 3. Запустите в режиме разработки
npm run tauri dev

# 4. Соберите релизную версию (появится в src-tauri/target/release/)
npm run tauri build
