Свитчер раскладки

Автоматическое исправление слов, набранных не в той раскладке

Выключен

Свитчер работает автоматически: исправляет слова по словарю сразу после пробела, а Double Shift переводит последнее слово или выделенный текст в любом случае. Системное сочетание Windows (Alt + Shift или Win + Space) свитчер не перехватывает.

Double Shift конвертирует последнее слово или выделенный текст. В приложениях из списка свитчер не работает.

Эти слова свитчер не исправляет. Если автозамена ошиблась, нажмите Backspace дважды сразу после неё — появится предложение добавить слово сюда.

DNS и DoH

Смена DNS-серверов для выбранного сетевого подключения

Текущие DNS: —

Можно указать IPv4 или IPv6. DoH подключается автоматически только для известных серверов (Cloudflare, Google, Quad9, AdGuard).

Для маршрутизации конкретных доменов используйте AdGuard Home или dnsmasq.

Изменение DNS требует прав администратора — Windows покажет запрос UAC. Сброс возвращает настройки роутера (DHCP).

Блокировка QUIC

Правило брандмауэра: UDP 80/443 наружу (помогает, когда сайты грузятся по QUIC в обход Zapret)

Hosts

Записи Zapret Tools в системном файле hosts

Формат: IP и один или несколько доменов через пробел. Управляемый блок в файле помечен # >>> Zapret Tools.

Запись в hosts требует прав администратора (UAC). Остальные строки файла не изменяются.

Инструменты

EXE-файлы в папке активной сборки Zapret

Здесь появятся сторонние программы для обхода блокировок (ByeDPI, TG WS Proxy), если вы положите их .exe файлы в папку с Zapret.

Запуск выполняется с рабочей папкой сборки. «Остановить» завершает процесс, запущенный из этой папки.

Подтверждение

Авто-подбор стратегии (Blockcheck)

Укажите домены для проверки. Если в сборке есть blockcheck.cmd, будет запущен он. Иначе программа по очереди запустит .bat-стратегии из корня сборки и проверит доступность доменов. Если стратегий нет, скачайте папку blockcheck с GitHub bol-van и положите её в папку с Zapret.

Проверка выполняется, это может занять несколько минут…
